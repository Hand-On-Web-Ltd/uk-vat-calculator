# UK VAT Calculator 🧮

A simple calculator for UK VAT (20%). Enter an amount, see the net, VAT, and gross figures instantly. Works both ways — add VAT to a price or remove it.

## Features

- Standard UK VAT rate (20%)
- Add VAT to a net amount
- Remove VAT from a gross amount
- Instant calculation as you type
- Works in any browser, no dependencies
- Print-friendly

## How to Use

1. Open `index.html`
2. Enter an amount
3. Choose "Add VAT" or "Remove VAT"
4. See the breakdown

## Example

- Net: £100.00
- VAT (20%): £20.00
- Gross: £120.00

Or working backwards from gross:
- Gross: £120.00
- VAT (20%): £20.00
- Net: £100.00
